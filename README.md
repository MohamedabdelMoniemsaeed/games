# Green Valley Farm (Farmly)

A bilingual (English / Arabic) farm management web app built for monitoring crops, livestock, weather, analytics, and harvest schedules.

## Features

- **Bilingual Interface**: Full English and Arabic localization with instant toggle (`AR` / `EN`) and dynamic RTL/LTR layout mirroring.
- **Interactive Farm Map**: Top-down visual farm map with selectable zones (Farm House, Tomato Field, Vegetable Field, Corn Field, Animal Area, Water Tank) and detailed zone telemetry.
- **Livestock Management**: Complete herd overview (cows, chickens, sheep, goats), feeding schedules with interactive completion tracking, animal profiles with weight histories, vaccination records, and custom notes.
- **Live Weather & Recommendations**: Interactive weather simulation across 5 conditions (Sunny, Clouds, Wind, Rainshower, Clearing up) with live farm recommendations (smart watering, skip irrigation, plant window).
- **Harvest Planning**: Crop readiness timelines with countdowns, yield estimates, and harvest logging.
- **Farm Analytics**: Multi-period production reporting (week, month, season), water efficiency ratings, and crop yield breakdowns.
- **Themes & Persistence**: Dark and light mode support with local storage persistence for settings, tasks, and notes.

## Run

```bash
npm install
npm run dev
```

Dev server runs on port 3000 (`http://0.0.0.0:3000`).
